FAQ

Policies, limits, and privacy basics.

How large can files be?

The default cap is 200 MB per file. Change MAX_FILE_SIZE_MB in the environment to adjust.

Which file types are disallowed?

Executables by default (.exe, .bat, .cmd, .sh). Configure DENY_EXTENSIONS to tighten further.

How long do temporary uploads last?

You can pick 1h, 12h, 24h, or 72h. Files purge automatically once expired.

Do I need an account?

No. Anonymous uploads work instantly. Accounts add dashboards, history, and short-link tracking.

Is there an API?

Yes. Use POST /api/upload for programmatic uploads and POST /api/delete with the delete token.
