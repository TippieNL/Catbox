Browser helper

Use any fetch-capable script to POST /api/upload with a base64 payload. The response returns a direct link.

View fetch docs

CLI snippet

node -e "const fs = require('node:fs');
const data = fs.readFileSync('file.jpg').toString('base64');
fetch('https://your-host/api/upload',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({filename:'file.jpg',content:data})}).then(r=>r.json()).then(console.log);"
