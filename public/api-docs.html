API reference

Simple endpoints for uploads, deletes, and short links.

POST /api/upload

JSON payload: { filename, content (base64), temporary?: boolean, expiryHours?: number }. Returns file_url, delete_token, expires_at.

POST /api/delete

JSON payload: { fileId, deleteToken }. Requires owner session or matching delete token.

POST /api/register & /api/login

Provide email and password. Successful requests set an HttpOnly session cookie for dashboard access.

GET /api/me

Returns the authenticated user plus their files and short links.

POST /shorten

Body: { url }. Response includes a short_url and code. Redirects live at /s/:code.

Endpoints stay lean to match the no-nonsense ethos.
